# Public Repository Publication Note

NOMI began as a private engineering project in **2026**.

This public repository is a **sanitized external-review artifact** prepared later in 2026. Its purpose is to make selected architecture, validation evidence, design decisions, and implementation boundaries visible to recruiters and technical reviewers without publishing the private NOMI source tree.

## Commit-history boundary

The public repository's commit history begins when this case-study package is published.

That history therefore represents:

- public documentation changes
- evidence/caveat maintenance
- recruiter-facing architecture updates
- public validation-guardrail changes

It does **not** represent the full history of NOMI's private development repository.

No attempt should be made to backdate, synthesize, or fabricate public commits to make the case-study repository appear older than it is.

## What demonstrates project history instead

Historical project evidence is represented through documented checkpoints, versioned private-development records, validation artifacts, and the implementation-boundary documentation included in this case study.

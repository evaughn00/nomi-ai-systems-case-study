# Screenshots

This directory is reserved for **sanitized recruiter-facing screenshots**.

Before adding an image:

- remove personal data
- remove credentials, tokens, private paths, and hostnames
- remove recovery/security-sensitive information
- confirm the image does not imply a live runtime when it is a prototype
- add a caption that identifies the artifact as implementation, prototype, or simulation

Recommended first screenshots:

1. Living Workspace / system overview
2. Provenance or governance surface
3. Domain/subsystem overview
4. System Health / implementation-boundary view

Do not copy screenshots from the private repository without a manual privacy review.
